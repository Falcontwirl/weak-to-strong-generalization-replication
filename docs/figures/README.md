# Write-up figures

Generated by `python scripts/writeup_figures.py` from `outputs/<run>/` (run IDs as in the CLAUDE.md
experiment log). All accuracies are SST-2 test accuracy (872 examples) unless noted, averaged over 3
seeds; error bars are the standard deviation across seeds. Colors: weak-to-strong student = blue,
weak teacher = orange, models trained on true labels = black.

| file | caption |
|---|---|
| `fig1_pgr_setup.png` | What PGR measures, for 160M → 2.8B (E4). The student, trained only on the 160M teacher's labels, closes part of the gap between the teacher and the 2.8B ceiling. |
| `fig2_all_pairs.png` | Teacher, weak-to-strong student and ceiling for all 10 pairs (E4), with PGR (mean ± sd of per-seed PGRs). Students clearly beat 160M teachers; with stronger teachers the gap to the ceiling is 2–4 points and gains are within seed noise. |
| `fig3_accuracy_band.png` | Accuracy after fine-tuning on true labels vs model size (SST-2: E4; BoolQ: E6), pooling each model's teacher and ceiling jobs; dashed lines = always predicting the test set's majority class. SST-2 compresses all sizes into 0.84–0.93; BoolQ sits just above its 0.622 majority baseline. BoolQ was not class-balanced, unlike the paper. |
| `fig4_chain_vs_direct.png` | Daisy chain on SST-2 (E2): each generation taught by the previous one, vs models trained on true labels and students taught directly by 160M. The chain ends at the same accuracy as direct supervision (1.4B: 0.863 vs 0.863). |
| `fig5_error_correlation.png` | Error correlation φ between models (E2). Models in the chain share mistakes far more (φ 0.57–0.77) than same-size models trained independently on true labels (0.33–0.48). |
| `fig6_confidence_loss.png` | Confidence loss vs naive loss with identical teachers (paired), one dot per student and seed. E3: α 0.75 for every student with the paper's linear 20% warmup (the paper uses 0.75 only for its largest students, 0.5 otherwise). E9: the released code's settings. E10: α = 0, which reproduces the naive runs exactly. |
| `fig7_pgr_heatmap.png` | PGR by teacher × student (E4). Hatched gray: the seed-to-seed spread exceeds the mean, so the sign of PGR is not reliable. |
